    Import from a CSV or TXT file

    A CSV file is a spreadsheet saved as plain text. In Excel or Google Sheets, use File → Save as / Download → CSV. A plain .txt file works too, as long as it is written in the same format (see below).

    How to format the CSV file

    Use one row per question. Column A is the type, column B is the question, and the columns after that are the answers.

    • mc (multiple choice): put the correct answer first, then the wrong answers, at least one. The game shuffles them.
    • msa (select all that apply): write correct: before every correct answer, for example correct:Mars, and nothing before the wrong ones. The game shuffles them.
    • slider: write the minimum, maximum and step, then the correct number, or the low and high ends of the correct range, one per column (for example slider,Question,0,10,1,3,5).
    • tf (true / false): one answer, either true or false.
    • fr (free response): list every answer you want to accept, one per column. Case and extra spaces are ignored. To accept a number within a tolerance, list the numbers and add one more column such as tolerance:0.1.
    • match (matching): write each pair as term=definition, one per column, 2 to 6 pairs. To put an = sign inside a term or definition, write \= instead.
    • order (ordering): list the items in the correct order, one per column, 2 to 6 items. The game shuffles them.
    • group (groups): write each group's name as group:Name, followed by the items that belong in it, one per column (for example group,Sort these,group:Planets,Mars,Venus,group:Stars,Sirius). 2 or 3 groups, up to 12 items in all.

    The text formatting from the question form works in the CSV too.

    To give a question a picture, put one extra cell right after the question text, written image:https://example.com/picture.png. The other cells stay as they are, and rows without a picture need nothing.

    To add an explanation shown after the player answers, put a cell written why:Because the cell makes energy. in the same place (before the answers, before or after the picture cell).

    A first row starting with type is treated as a header and skipped. A row with a problem is skipped and listed after you import, so the good rows still load. Example:
