    Add a question

    You can format text: **bold**, *italic*, __underline__, E = mc^2^ (superscript), H~2~O (subscript). This works in the question, multiple choice answers, and matching terms and definitions.

    More about text formatting
    • _italic_ works the same as *italic*
    • Marks can be combined: **bold _and italic_**
    • Superscript and subscript cannot contain spaces, so x^2 + y^2 stays as typed
    • Put a backslash before * _ ^ or ~ to show it as plain text.

    Pairs (each term goes with the definition beside it)
    Term Definition

    2 to 6 pairs. The game shuffles the definitions, and the player drags each one onto its term.

    Import from a CSV or TXT file

    A CSV file is a spreadsheet saved as plain text. In Excel or Google Sheets, use File → Save as / Download → CSV. A plain .txt file works too, as long as it is written in the same format (see below).

    How to format the CSV file

    Use one row per question. Column A is the type, column B is the question, and the columns after that are the answers.

    • mc (multiple choice): put the correct answer first, then the wrong answers, at least one. The game shuffles them.
    • tf (true / false): one answer, either true or false.
    • fr (free response): list every answer you want to accept, one per column. Case and extra spaces are ignored.
    • match (matching): write each pair as term=definition, one per column, 2 to 6 pairs. To put an = sign inside a term or definition, write \= instead.

    The text formatting from the question form works in the CSV too.

    A first row starting with type is treated as a header and skipped. A row with a problem is skipped and listed after you import, so the good rows still load. Example:
